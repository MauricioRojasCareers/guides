Your Herdr 0.8.2 setup

Herdr, from zero

A practical first-day guide to the terminal workspace manager already configured on this computer. Start with the mouse, learn one prefix key, and let your shells and coding agents keep running when you disconnect.

First: it is spelled herdr.

There is no second “e.” Run herdr, not herder. Your Herdr server is already installed and configured.

The mental model

Session

The persistent background Herdr server. Closing your terminal only detaches the view; it does not kill your work.

Workspace

A project-level container. A good default is one workspace for each repo or investigation.

Tab

A layout inside a workspace. Use tabs for views such as agent, logs, server, and tests.

Pane

A real terminal inside a tab. Panes can sit side-by-side or one above another.

An agent is a coding-agent process Herdr recognizes in a pane. The sidebar can show whether it is working, blocked for your input, done, idle, or unknown.

Your first session

  1. Start from the project you want to work on.
    cd /path/to/your/project
herdr
  2. Use the terminal normally. Run commands, editors, servers, or an agent such as codex inside the pane. Herdr sits around the terminal; it does not replace your shell.
  3. Use the mouse at first. Click panes, tabs, workspaces, and agent rows to focus them. Right-click for actions. Drag pane borders to resize. Drag over text to select and copy it.
  4. Detach when you are leaving. Press Ctrl+B, release both, then press Q. You can also close the outer terminal window. The server, panes, and agents remain alive.
  5. Reattach later. Open a terminal and run herdr again. Your session returns.
Detach is not stop.

Ctrl+B, then Q, leaves everything running. herdr server stop actually ends the default session and its panes. Do not use the stop command merely to exit the UI.

How the prefix key works

Most keystrokes must reach the shell or program inside the pane. Herdr therefore reserves one starter key—called the prefix—and interprets only the next key as a Herdr action.

Ctrl + B release, then C → create a new tab

This guide writes that sequence as Prefix C. Do not hold Ctrl while pressing the action key. If you get lost after pressing the prefix, press Esc and try again.

The shortcut you should memorize first:

Press Prefix ? to open Herdr’s live help showing every active binding. In the help screen, press / to filter, Backspace to edit the filter, and Ctrl+U to clear it.

Copying and scrolling

Easy: use the mouse

Drag to select terminal text. Your current setup uses Herdr’s normal mouse behavior, so selection copies automatically. Use the mouse wheel to move through scrollback.

Keyboard: copy mode

Enter with Prefix Y, then:

  • H/J/K/L move around.
  • V or Space begins selection.
  • Y or Enter copies.
  • / searches forward; ? searches backward.
  • N repeats a search; Shift+N reverses it.
  • Q or Esc cancels/exits.

A sensible everyday layout

For one project, keep a single workspace and give each responsibility a clear place:

Tab 1 — agent

Run Codex or another coding agent in the main pane. Split right for a normal shell where you can inspect Git, files, or test output.

Tab 2 — runtime

Run the application or development server here. Add another pane below for logs or a long-running test watcher.

# In your project pane
codex

# Prefix %, then use the new pane for ordinary commands
git status

# Prefix C, then run a server in the new tab
npm run dev

When an agent needs approval or finishes, its state appears in the sidebar. Click that agent row—or use Prefix G—to jump to it.

Workspaces versus named sessions

Use a workspace for another project or repo. Workspaces share one Herdr background session and are designed for ordinary organization.

Named sessions are fully separate servers and state. Most people do not need them initially. If you eventually want a hard boundary between “work” and “personal,” the basic commands are:

herdr session list
herdr session attach work
herdr session attach personal

Phone and remote use

Herdr runs where the work and code live. From a phone or another computer, SSH into this Linux machine and attach to the same persistent session:

ssh mauricio@your-linux-machine
herdr

Herdr adapts to a narrow terminal. Detach with Prefix Q, disconnect SSH, and reattach later. A separate advanced option is herdr --remote <ssh-host>, which uses the local Herdr binary as a thin client for a remote server.

If something feels wrong

  • A shortcut does nothing: press Prefix ? and confirm the active binding. The outer terminal or desktop may have intercepted the keystroke.
  • You cannot type Ctrl+B into a program: press Ctrl+B twice to send a literal prefix through in direct agent attach; in the full UI, cancel prefix mode with Esc if needed.
  • An agent is not recognized: it still works as a normal terminal process. Use herdr agent list and herdr agent explain <target> to inspect detection.
  • You reopened Herdr in the wrong directory: the default session persists independently of your current shell. Use the workspace picker rather than expecting a new herdr command to replace the running session.
  • You think work disappeared: run herdr status, then herdr. Detaching or closing a client normally leaves panes running.
