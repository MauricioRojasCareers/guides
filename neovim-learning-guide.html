Your unusual Escape mapping:

Esc in Insert mode returns to Normal mode normally. Once you are already in Normal mode, pressing Esc again saves the file. In practice, double-Escape after typing saves. You can always use :w when you want the intent to be explicit.

The idea that creates proficiency

Vim commands form a grammar. Instead of learning each edit as an unrelated shortcut, combine a count, an operator, and a movement or text object:

[count]+ operator+ motion / text object

d means delete, c means change, and y means yank (copy). A motion answers “how far?” A text object answers “what thing?”

CommandRead it asResult
dwdelete → word motionDelete forward to the next word.
3dwthree × delete wordDelete three words.
ciwchange → inside wordReplace the current word, wherever the cursor is inside it.
ci"change → inside quotesReplace the text between quotes, keeping the quotes.
da(delete → around parenthesesDelete the contents and surrounding parentheses.
yapyank → around paragraphCopy a whole paragraph including surrounding whitespace.
>ipindent → inside paragraphIndent the current paragraph.
=a{format → around bracesReindent a brace-delimited block.

Learn i as “inside” and a as “around,” then combine them with w word, p paragraph, " quotes, ' single quotes, ` backticks, (, [, and {. This one pattern replaces dozens of memorized edits.

Movement worth learning

Within a line

  • w / b / e — next word, previous word, end of word
  • 0 / ^ / $ — start, first nonblank, end of line
  • f{char} — jump onto the next character
  • t{char} — jump just before the next character
  • ; / , — repeat / reverse the last f or t
  • % — jump to a matching bracket

Across a file

  • gg / G — first / last line
  • 42G or :42 — line 42
  • { / } — previous / next paragraph
  • Ctrl+U / Ctrl+D — half-page up / down
  • Ctrl+O / Ctrl+I — older / newer jump location
  • mA, then 'A — set and return to a file mark

Your relative line numbers make counts practical: if the destination shows 12, type 12j or 12k. Prefer searches and meaningful motions over repeatedly tapping j.

Searching, changing, and repeating

CommandUse
/text, then n / NSearch forward; repeat forward or backward. Search ignores case unless your query contains a capital.
* / #Search forward / backward for the word under the cursor.
:s/old/new/gReplace every match on the current line.
:%s/old/new/gcReplace throughout the file, asking for confirmation.
.Repeat the last change. This is one of Vim’s highest-value commands.

qaq … q, then @aRecord keystrokes into macro register a, stop, then replay them.
@@Repeat the most recently executed macro.

Think “make one edit repeatable.” Use ciw instead of deleting characters one at a time, then move to the next target and press .. Use a macro only when the repeated job involves navigation or several edits.

Insert commands you should distinguish

KeysMeaning
i / aInsert before / append after the cursor.
I / AInsert at the first nonblank / append at line end.
o / OOpen a new line below / above, then enter Insert mode.
s / SReplace one character / replace the whole line.
C / DChange / delete from the cursor to line end.
r / RReplace one character / enter Replace mode.
JJoin the next line onto this one.

Your familiar sequence is G followed by o to jump to the bottom and open a line below, or G followed by uppercase O to open above. These are sequences, not keys pressed simultaneously.

Visual mode, registers, and the clipboard

v selects characters, V selects whole lines, and Ctrl+V creates a rectangular block selection. Apply an operator after selecting: d, y, c, >, or =.

Your default register is the Linux system clipboard.

The configuration sets clipboard=unnamedplus, and xclip is available. Normal yanks, deletes, and changes therefore interact with the system clipboard. The custom Visual-mode p mapping preserves the clipboard when you paste over selected text.

Oil and Neogit can change real files and Git state.

In Oil, you can rename, move, create, or delete by editing directory lines and saving with :w; review its confirmation carefully. In Neogit, x discards the selected change. Use ? when uncertain.

Buffers, Neovim windows, and Herdr panes

These layers are different:

Buffer

An in-memory file. Closing a window does not necessarily unload its buffer. Use Space b to switch.

Neovim window

A view onto a buffer inside one Neovim process. Create with :split or :vsplit; move with Ctrl+W h/j/k/l.

Herdr pane

A separate terminal process outside Neovim. Your Herdr shortcuts are Ctrl+B, then % or ".

A practical layout is Neovim in one Herdr pane and a shell/test runner in another. Inside Neovim, use buffers for most file switching; create Neovim splits only when you genuinely need two files visible together.

A four-stage path to proficiency

  1. Stage 1 — movements and clean mode changesRun vimtutor. Practice w b e 0 ^ $ f t ; , / n N, plus i a I A o O. Always return to Normal mode when you finish inserting.
  2. Stage 2 — editing grammarFor one week, deliberately use d/c/y with motions and text objects. Focus on ciw, ci", da(, yap, counts, and ..
  3. Stage 3 — projects, history, and repetitionUse Space f/s/b/e for navigation, Ctrl+O/I for jump history, registers for controlled paste, and a small macro for repetitive edits.
  4. Stage 4 — code intelligenceAfter the editing language feels natural, add language servers, completion, and Treesitter for the languages you actually use. Add them intentionally rather than replacing this config with a giant distribution.
A sustainable practice rule:

Choose two commands per week. Put them on a sticky note and force yourself to use them until they become automatic. Speed arrives from composing familiar commands, not from trying to memorize an entire cheat sheet.

Ten-minute daily drill

  1. Open a real project with nvim ..
  2. Use Space f to open a file and Space s to find a symbol or phrase.
  3. Make three edits using text objects: for example ciw, ci", and da(.
  4. Repeat one edit with ..
  5. Navigate away with a search or gd if LSP is attached; return with Ctrl+O.
  6. Inspect your changes with Space g, but keep committing optional while you learn the UI.
  7. Save explicitly with :w, or press Escape once more after reaching Normal mode.
