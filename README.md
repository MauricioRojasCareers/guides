# Guides

Mauricio's practical technical reference guides, published as a static site with GitHub Pages.

The site is deployed automatically by GitHub Actions whenever `main` is updated.

## Local preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
